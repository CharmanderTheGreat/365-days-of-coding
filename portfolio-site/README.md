# Personal Portfolio Site

My personal portfolio website — built with plain HTML, CSS, and
JavaScript, no frameworks or build tools.

**[Live site](https://charmanderthegreat.github.io/Personal-portfolio-site--HTML-CSS-JS-/)** 

## Features

- Responsive layout with a collapsible mobile nav menu
- Smooth-scrolling in-page navigation
- Google Fonts (Inter + Poppins)

## Project structure

```
.
├── index.html
├── style.css
└── script.js
```

## Running locally

No build step needed — just open `index.html` in a browser, or serve
the folder:

```bash
npx serve .
```

## Deployment

Deployed via GitHub Pages: Settings → Pages → select the branch
serving `index.html`.

## Tech

HTML, CSS, JavaScript.
