# Responsive Navbar Component

A practice project demonstrating a responsive navbar and mobile menu
pattern in plain HTML, CSS, and JavaScript — built around a mock
watch-store landing page ("Robiñol Timepieces").

> The brand name and product listings are fictional, created for
> demonstration purposes only. Product images are royalty-free stock
> photos sourced from Unsplash.

**[Live demo](https://charmanderthegreat.github.io/Responsive-navbar-component/)**

## What this demonstrates

- **Responsive navbar** that collapses into a toggleable mobile menu
  below a breakpoint, with the menu auto-closing after a link is
  clicked
- **Smooth-scroll** in-page navigation via anchor links
- A responsive product grid (hero banner + card grid) as a real
  layout for the navbar to sit on top of, rather than an isolated
  component

## Running locally

No build step needed — just open `index.html` in a browser, or serve
the folder:

```bash
npx serve .
```

## Deployment

Deployed via GitHub Pages: Settings → Pages → select the branch
serving `index.html`.
